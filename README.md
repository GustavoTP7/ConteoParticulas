# Registro de Conteo Mineralógico - Método Cánepa

Esta aplicación permite registrar partículas libres y mixtas siguiendo el método del Dr. Cánepa.

## Instrucciones:
1. Crea un repositorio en GitHub.
2. Sube `app.py` y `requirements.txt`.
3. Conecta el repositorio a [Streamlit Cloud](https://share.streamlit.io/).
